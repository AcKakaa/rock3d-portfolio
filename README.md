# 纪亨东 · 项目作品集

同一简历二维码下的两项独立项目展示：

- [Rock3D：岩石识别与三维几何测量](rock3d/)
- [高光谱 × 三维地质：岩性分区与空间验证](hyperspectral/)

## 更新现有 GitHub Pages

继续使用现有仓库 `AcKakaa/rock3d-portfolio` 和原发布来源。把此目录里面的全部内容上传到发布目录，确保本文件同级的 `index.html` 位于发布目录根部，而 `rock3d/` 和 `hyperspectral/` 是它的两个子目录。

不要把 ZIP 文件本身作为网站上传，也不要在发布目录外再套一层 `site/` 文件夹。原仓库中既有文件可保留，同名首页以本版本更新。

保持原仓库名、Pages 发布来源和网址，原二维码仍访问：

https://ackakaa.github.io/rock3d-portfolio/

两个项目分别位于该网址下的 `rock3d/` 与 `hyperspectral/`。旧网址中的 `#industry`、`#journey` 等 Rock3D 章节链接会转到对应的 Rock3D 页面。

## 来源与范围

Rock3D 使用 2026-10-23 下载的当前公开仓库快照；新项目使用用户提供的 GitHub Pages 压缩包。整合仅新增总览页与公共导航，未重跑研究、改变图件、数据、指标、原有算法或实验状态。模拟模块沿用各项目原有的来源和边界说明。

本地 Chrome 已验证导航、资源、模型与原有交互。公网发布后仍应实际扫码检查手机和微信中的显示、视频播放及下载。

# 高光谱三维岩性分区与空间验证

纪亨东｜个人研究项目｜Python · hylite · scikit-learn

从 hylite 公开小样例出发，完成连续统去除、PCA/聚类、USGS 参考谱探索和已有高光谱点云属性展示；接入 Tinto Mini，开展数据准入与孤立单波段下陷质控试验；随后完成完整 Tinto 的固定模型对照、三维误差解释与内部空间验证。

## 数据与方法
Tinto 3,242,964 点，141 个 SWIR 波段；分析 2104.60–2378.67 nm 的 51 波段。
共同有效非植被训练 289,863 点，官方共同测试 2,573,213 点。
R：原始反射率；Q：上包络连续统去除 R/C；S：(1−Q)/‖1−Q‖₂。
六类标签；固定随机森林 100 棵树，max_depth=16，min_samples_leaf=5，class_weight=balanced，seed=42。

## 官方共同测试：OA / 宏 F1 / mIoU
R：72.78% / 59.61% / 45.81%
Q：70.68% / 58.12% / 44.27%
S：71.83% / 59.46% / 45.58%
R 硫化物类精确率 31.62%、召回率 65.80%；173,926 个假阳性中，152,249 个原标签为页岩（87.54%）。

## 原训练区内部空间验证：OA / 宏 F1 / mIoU
289,863 点，355 个三维空间块，三折空间分组分层划分，固定距离缓冲，共 9 个森林。
R：87.47% / 80.49% / 68.54%
Q：84.86% / 76.55% / 63.82%
S：85.19% / 77.07% / 64.61%
R 硫化物类精确率 60.37%、召回率 72.83%。

两套成绩来自不同点集，不可将其差值称为方法提升。R 在本次官方共同测试及内部验证中整体最好，未证实 Q/S 稳定整体优越。质控规则仅保留为候选告警，未自动修复正式数据。

## 项目工作与边界
工作覆盖公开数据适配、波长/标签/掩膜/点序核查、分块/内存映射缓存、光谱表示对照、固定分类器评估、三维诊断与可追溯归档。使用开源工具和 AI 辅助编程，在实验室执行和核对实验。
点云已有光谱；未完成原始影像到点云的配准或投影。坐标单位/CRS 未核实。标签一致性不等于逐点独立化验。未完成跨矿区验证、多源找矿融合、靶区圈定或品位估计。本项目独立于 Rock3D。

数据来源：Tinto，DOI 10.14278/rodare.2256；hylite；USGS Spectral Library Version 7，DOI 10.5066/F7RR1WDJ。
